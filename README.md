# esbocos-leads

Repositorio para hospedar esbocos de landing pages de captura de leads da CUCA, publicados via GitHub Pages para revisao e aprovacao de clientes e prospects.

Site publicado em: https://cucaestudiocriativo.github.io/esbocos-leads/

## Esbocos publicados

O Velho Eurico (v6): https://cucaestudiocriativo.github.io/esbocos-leads/velho-eurico-esboco-v6.html

## Como adicionar um novo esboco

Suba o arquivo .html na raiz do repositorio (ou em uma pasta propria). Ele fica acessivel automaticamente em https://cucaestudiocriativo.github.io/esbocos-leads/nome-do-arquivo.html. Depois, adicione o link aqui na secao de esbocos publicados.
